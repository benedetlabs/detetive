# 🕵️‍♂️ Detetive Estrela - Assistente de Investigação

Aplicativo web leve e otimizado para celular para auxiliar jogadores do jogo de tabuleiro **Detetive (Estrela)**.

## 📱 Recursos

- 📋 **Cartão de Anotações Interativo**: Tabela responsiva com rolagem suave, coluna de cartas fixa e marcadores instantâneos por toque.
- 🧠 **Dedução do Envelope**: Cálculo automático de probabilidades e identificação dos itens restantes (Suspeito, Arma e Local).
- 🃏 **Mão Inicial**: Registro rápido das suas cartas no início da partida.
- 📜 **Histórico de Palpites**: Registro das jogadas da mesa com inferências lógicas automáticas.
- 📱 **PWA & Offline**: Funciona offline em qualquer celular, podendo ser adicionado à Tela de Início do iOS ou Android.

## 🚀 Como Rodar Localmente

```bash
python3 -m http.server 8000
```
Acesse `http://localhost:8000` no seu navegador.
